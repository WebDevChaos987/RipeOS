# RipeOS
Welcome to RipeOS; a virtual computer, in it's First Version. **WARNING**: RipeOS, is currently in it's Beta, and does **NOT** support Mobile
# Features
Currently this Operating System, is a terminal (not graphical). You can access the web, change font colours, and background colours, too.
